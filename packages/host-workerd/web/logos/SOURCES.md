# Logos

Monochrome marks for agents and model providers, drawn with `currentColor` through a CSS mask (`.app-icon .icon-mask`). Used nominatively ("works with", "connects to"); each belongs to its owner.

- From [Simple Icons](https://simpleicons.org) 16.35.0 (CC0-1.0): anthropic, claude, cursor, githubcopilot, googlegemini, openrouter.
- From [LobeHub Icons](https://github.com/lobehub/lobe-icons) (`@lobehub/icons-static-svg`, MIT): openai (Simple Icons no longer carries it). The same file as hewn.tools.

`<title>` and `role` stripped, `fill="currentColor"` added; paths unchanged.
